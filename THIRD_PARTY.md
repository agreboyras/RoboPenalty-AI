# Componentes externos y derechos

Este documento identifica procedencia; no otorga permisos de terceros ni impone una licencia al código propio sin acuerdo de sus autores.

| Componente | Procedencia/uso | Estado de distribución |
|---|---|---|
| FreeKick, ONNX, movimiento NPZ, escena/modelo del delantero | Instalación local adaptada de RoboNaldo_Deploy; upstream OpenDriveLab/RoboNaldo_Deploy; repositorio previo del equipo agreboyrasFacu1/TP07-IA-G1-Futbol | No se incluyen. Licencia/alcance de redistribución pendientes; uso local no concede permiso de redistribuir |
| G1 del arquero y meshes | unitreerobotics/unitree_mujoco, LICENSE local BSD-3-Clause | Se leen desde carpeta hermana. Si el equipo decide distribuirlos deberá conservar licencia y atribuciones aplicables |
| Whisper tiny convertido | Systran/faster-whisper-tiny, conversión de OpenAI Whisper | Procedencia local documenta MIT; conservar LICENSE-OpenAI.txt/README/PROVENANCE. Binario excluido; voz pendiente |
| MuJoCo, ONNX Runtime, NumPy y demás paquetes Python | Instalación de paquetes, no vendorizados | Consultar sus licencias/avisos en las distribuciones; requirements no redistribuye las bibliotecas |

Las simulaciones y reportes propios no transfieren derechos sobre modelos o pesos usados para generarlos. No se copiaron nuevos assets externos durante la preparación de esta publicación. El estadio usa geometría procedural propia y no se publican escudos oficiales. El equipo todavía debe elegir y documentar la licencia del código propio; no se creó una LICENSE global que pudiera cubrir incorrectamente terceros.
